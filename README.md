# Agrim Kasaju — Engineering Portfolio

Personal engineering portfolio showcasing applied projects in autonomous AI agents, real-time embedded edge ML, operating systems concurrency, and low-level Linux systems software.

Built with **React**, **Vite**, **Tailwind CSS**, and dynamic project-driven CSS variables.

🔗 **Live Deployment:** [agrimkasaju.netlify.app](https://agrimkasaju.netlify.app)

## Featured Projects

1. **[Anubis (Voice-Activated AI Assistant)](https://github.com/agrimkasaju/Anubis)** — Autonomous agentic workflow in Python with sub-800ms execution, real-time custom Orion ONNX wake-word model (<150ms latency), and IPC memory bridge.
2. **[Smart Inventory System](https://github.com/agrimkasaju/Smart-Inventory-System)** — Real-time Raspberry Pi edge inference pipeline with INT8 quantized TensorFlow Lite (4x FPS speedup, 75% model size reduction) and Firebase sync.
3. **[API Search Platform](https://github.com/agrimkasaju/API_search)** — Scalable full-stack application aggregating 4+ external REST endpoints with sub-200ms query latency and centralized Redux state.
4. **[CPU Scheduling Simulator](https://github.com/agrimkasaju/Scheduler-Algorithm)** — FCFS, Round Robin, and preemptive priority algorithms in C/C++ Linux with POSIX threads, semaphores, and shared memory.

## Local Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

Configured for automated build and single-page application routing on Netlify via `netlify.toml` and `public/_redirects`.
